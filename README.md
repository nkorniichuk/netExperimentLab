# Лабораторна робота з комп’ютерних мереж

**Передача файлу через SRT у Docker**

- **Студентам** видайте каталог `student/`. Початок роботи в `student/LAB.md`, теорія в `student/NOTES.md`, шаблон результатів у `student/REPORT.md`.
- **Викладачеві** відкрийте `teacher/GUIDE.md`. Повне рішення, включно з Compose, у `teacher/reference/`.
